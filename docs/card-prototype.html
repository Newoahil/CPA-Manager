原型里删掉的东西

  • 灰块圆角：column 不支持。改用 interactive_container 才有圆角，但必须设置点击行为，整块可点、易误触。改为直角。
  • 异常块左侧红边：飞书没有单边边框。改为浅红底 + 排第一。
  • 每个块里的细进度条：飞书唯一的进度条是 chart 组件的 linearProgress。本项目之前在生产上渲染过，3 根条占约 200px，且官方建议单卡最多 5 个图表——无法做成每块一根细条。去掉，靠大号百分比 + 状态标签。

单个渠道块的 JSON 骨架

③ ⑤ ⑥ 三项组合后的实际结构，所有字段均出自官方文档：

{ "tag": "column_set", "flex_mode": "none", "margin": "0px 0px 8px 0px", "columns": [{ "tag": "column", "width": "weighted", "weight": 1, "background_style": "grey-100", // ③ 灰底；异常时改 red-50 "padding": "10px 12px 10px 12px", "elements": [ { "tag": "column_set", "flex_mode": "none", // ⑤ 左右两列 "columns": [ { "tag": "column", "width": "weighted", "weight": 1, "vertical_align": "center", "elements": [{ "tag": "markdown", "content": "**<font color='blue'>Antigravity</font>** <text_tag color='green'>正常</text_tag>" }] }, { "tag": "column", "width": "auto", "vertical_align": "center", "elements": [{ "tag": "markdown", "content": "**<font color='green'>85%</font>**", "text_align": "right", "text_size": "heading-3" }] } ] }, { "tag": "markdown", "text_size": "notation", // ⑥ 副行 "content": "<font color='grey'>4 个号 · 最紧 Gemini 周 · 5 天后刷新</font>" } ] }] }

还需真机确认的只有两件事：
· grey-100 在深色模式下与卡片底色的对比是否够明显——不够就换 grey-200（深色 #373737）；
· 嵌套两列后，渠道名过长时右侧百分比是否被挤到下一行。
这两项文档无法判断，发一张真卡即可确认，不影响其它结构。
